About Kupass

Kupass (Aku - User - Pass) generates credentials locally with a cryptographically secure RNG. Nothing leaves your browser.

Privacy & Data: Credentials are generated locally and never sent to any server. Kupass uses localStorage to remember your preferences and inputs, and sessionStorage for temporary update sessions. Generated passwords are never saved permanently. Click the Power icon to clear all local data.

Power does not clear the clipboard. Use the button below if you need to clear it manually.

Backup & Update

Backup Pairs

Backup is required to update credentials later. Kupass does not persist credentials in the browser, so this file is the only way to preserve the results.

File contents:

• Platform, name, email, phone

• Username & password

• Format: .json (restorable)

Plaintext: File is not encrypted. Store in a safe place.

Update Pairs

Upload a .json backup. Kupass will use the formatting from the file to generate new passwords/usernames. The Username and Password tabs will be locked during this process.
