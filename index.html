About Kupass

Kupass (Aku - User - Pass) is a unified, transparent credential generator. All generation happens locally using a cryptographically secure random number generator.

Heads up: Generated credentials are never saved. If you are on a shared or public computer, click the Power icon in the top right to wipe your inputs before closing the tab.
